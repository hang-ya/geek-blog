* **定义**：Python 交互式 Shell 是一个可以让你逐条输入 Python 代码，并立即查看运行结果的环境。
* **适用场景**：它特别适合测试简单的 Python 代码、尝试新的语法或快速验证某个表达式，而不需要先创建完整的 Python 文件。
* **与 Python 脚本的区别**：

  * 交互式 Shell：输入一条代码，立即看到结果。
  * Python 脚本：将多行代码保存到 `.py` 文件中，然后一次运行整个程序。

## 什么是终端？

* **定义**：终端是一个基于文本的界面，你可以通过输入命令与计算机进行交互。
* **常见终端**：

  * macOS：Terminal
  * Windows：命令提示符（Command Prompt）或 PowerShell
  * Linux：GNOME Terminal、Konsole 等

## 启动 Python 交互式 Shell

打开终端，然后输入：

```bash
python
```

按下 `Enter` 后，Python 会启动交互式 Shell。

在某些 macOS 和 Linux 环境中，你可能需要使用：

```bash
python3
```

启动后，你可能会看到类似下面的内容：

```bash
Python 3.12.2 (main, Mar 21 2024, 22:48:26) [Clang 14.0.3] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

其中，`>>>` 是 Python 的提示符，表示 Python 正在等待你输入代码。

## 在交互式 Shell 中运行代码

例如，你可以直接输入 `print()`：

```py
print("Hello, world!")
```

运行后会立即看到：

```text
Hello, world!
```

然后 Python 会再次显示：

```text
>>>
```

这表示 Python 已经执行完上一条代码，现在可以继续输入新的代码。

你也可以直接计算数学表达式：

```py
2 + 3
```

结果：

```text
5
```

还可以创建变量：

```py
name = "Alice"
print(name)
```

输出：

```text
Alice
```

## 什么是 REPL？

Python 交互式 Shell 遵循一个称为 **REPL** 的运行过程。

REPL 是以下四个单词的缩写：

* **Read（读取）**：读取你输入的 Python 代码。
* **Evaluate（求值）**：执行并计算这段代码。
* **Print（打印）**：显示代码运行后的结果。
* **Loop（循环）**：再次等待你输入下一条代码。

例如：

```text
>>> 2 + 3
5
>>> 10 * 2
20
>>> print("Hello")
Hello
>>>
```

每次输入代码后，Python 都会完成一次“读取 → 求值 → 输出 → 等待下一条命令”的过程。

## 如果输入错误的代码会发生什么？

如果输入的代码不符合 Python 的语法，Python 会显示错误信息。

例如：

```py
something random
```

可能得到：

```text
>>> something random
  File "<stdin>", line 1
    something random
              ^^^^^^
SyntaxError: invalid syntax
```

这里的 `SyntaxError` 表示代码存在语法错误。

出现错误并不意味着 Python 交互式 Shell 关闭了。你仍然可以继续输入新的代码：

```text
>>> 2 + 2
4
```

## 如何退出 Python 交互式 Shell？

你可以使用 `exit()`：

```py
exit()
```

也可以使用操作系统对应的快捷键：

* **macOS / Linux**：`Ctrl + D`
* **Windows**：`Ctrl + Z`，然后按 `Enter`

退出后，你会回到普通的终端界面。

## 什么时候使用 Python 交互式 Shell？

Python 交互式 Shell 非常适合：

* 快速测试一行 Python 代码。
* 尝试新的运算符或函数。
* 检查某个表达式的结果。
* 学习 Python 基础语法。
* 做一些简单的代码实验。

例如，你刚学会了 `len()`，可以直接测试：

```py
>>> len("Hello")
5
```

如果你需要编写较长的程序，或者需要保存代码、管理多个文件，那么应该使用代码编辑器或 IDE，并将代码保存为 `.py` 文件。

## 总结

Python 交互式 Shell 是一个非常方便的 Python 实验环境：

```text
打开终端
   ↓
运行 python 或 python3
   ↓
进入 >>>
   ↓
输入 Python 代码
   ↓
立即查看结果
   ↓
继续输入下一条代码
```

对于 Python 初学者来说，交互式 Shell 是练习和验证代码的一个简单工具。
