# 什么是 Python？

**Python** 是一种通用的编程语言。

它最大的特点之一就是：

> **语法比较简洁，非常适合初学者入门。**

例如，用 Python 输出一句话，只需要：

```py
print("Hello World")
```

程序就会输出：

```text
Hello World
```

相比一些语法更加复杂的编程语言，Python 通常可以用更少的代码完成同样的任务。

> **一种用途非常广泛的编程工具。**

# 什么是变量（Variable）？

在程序中，我们经常需要保存一些数据。

例如：

```text
姓名：John Doe
年龄：25
```

如果希望程序记住这些数据，就可以使用：

**变量（Variable）**

变量可以理解成一个：

> **用来保存数据的名字。**

例如：

```py
name = "John Doe"
age = 25
```

可以理解成：

```text
name
 ↓
"John Doe"

age
 ↓
25
```

以后就可以通过变量名找到这些数据。

例如：

```py
print(name)
print(age)
```

输出：

```text
John Doe
25
```

---

# 如何创建变量？

Python 创建变量非常简单：

```text
变量名 = 数据
```

例如：

```py
name = "Alice"
age = 18
score = 95.5
is_student = True
```

这里：

| 变量           | 保存的数据     |
| ------------ | --------- |
| `name`       | `"Alice"` |
| `age`        | `18`      |
| `score`      | `95.5`    |
| `is_student` | `True`    |

其中：

```python
=
```

叫做：

**赋值运算符（Assignment Operator）**

它的作用不是“判断是否相等”，而是：

> **把右边的数据保存到左边的变量中。**

例如：

```py
age = 18
```

可以理解成：

```text
18
 ↓
保存到
 ↓
age
```

---

# Python 变量不需要提前声明类型

Python 是一种：

**动态类型语言（Dynamically Typed Language）**

简单来说：

> **创建变量时，不需要提前告诉 Python 这个变量是什么类型。**

例如：

```py
age = 18
name = "Alice"
score = 95.5
```

Python 会根据保存的数据自动判断类型。

例如：

```py
age = 18
```

Python 会知道：

```text
age 是 int 类型
```

而：

```py
name = "Alice"
```

Python 会知道：

```text
name 是 str 类型
```

所以不需要写成类似：

```text
int age = 18
```

Python 直接写：

```py
age = 18
```

即可。

# 变量命名规则

变量名称并不是随便写的。

Python 对变量名有一定要求。

## 规则一：不能以数字开头

正确：

```py
age = 18
name1 = "Alice"
```

错误：

```py
1name = "Alice"
```

因为变量名不能以数字开头。

---

## 规则二：只能使用字母、数字和下划线

例如：

```py
student_name = "Tom"
student_age = 18
```

是合法的。

---

## 规则三：变量名区分大小写

下面三个变量是不同的变量：

```py
age = 18
Age = 20
AGE = 30
```

Python 会把它们看成三个不同的名字。

因此：

```text
age
Age
AGE
```

并不相同。

---

## 规则四：不能使用 Python 关键字

Python 中有一些特殊单词已经被系统使用。

例如：

```text
if
else
for
while
class
def
return
True
False
None
```

这些叫：

**关键字（Keyword）**

不能把它们直接当作普通变量名。

例如：

```py
class = 10
```

就是错误的。

---

# 推荐的变量命名方式

如果一个变量由多个单词组成，通常使用：

**snake_case（蛇形命名法）**

也就是：

> **单词之间使用下划线 `_` 连接。**

例如：

```py
student_name = "Alice"
student_age = 18
total_score = 95
```

不要写成：

```text
studentname
student-name
student name
```

推荐：

```py
student_name
```

# 什么是注释（Comment）？

程序代码是给计算机执行的。

但是有时候，我们还需要给：

**人类程序员**

留下说明。

这就是：

**注释（Comment）**

注释的内容不会被 Python 当作普通代码执行。

---

# 单行注释

Python 使用：

```python
#
```

表示单行注释。

例如：

```py
# 这是一个注释

name = "Alice"
```

也可以写在代码后面：

```py
age = 18  # 保存学生年龄
```

---

# 为什么需要注释？

例如：

```py
score = price * 0.8
```

如果代码很多，过一段时间后可能会忘记：

```text
0.8 是什么意思？
```

可以写：

```py
score = price * 0.8  # 打八折
```

这样以后自己或者其他程序员就更容易看懂。

---

# 注意：三引号不是严格意义上的注释

很多初学者会看到：

```py
"""
这是一大段文字
"""
```

然后认为：

> 这是多行注释。

严格来说并不是。

`""" """` 创建的是一个：

**多行字符串（Multi-line String）**

例如：

```py
message = """
Hello
Python
"""
```

这里它是真正的字符串。

如果只是单独写：

```py
"""
这段文字没有赋值
"""
```

Python 通常不会产生可见效果，因此经常被拿来临时写大段说明。

但是学习 Python 时最好知道：

> **Python 没有专门的多行注释语法。**

如果是正式代码注释，通常还是使用：

```py
# 第一行注释
# 第二行注释
# 第三行注释
```

# 列表（list）

> **一组有顺序的数据。**


输出：

元组也是：

> **有顺序的数据集合。**

例如：

```py

```

输出：

```text

```

> **元组创建后，不能直接修改其中的元素。**

例如：


集合用于保存：

> **不重复的数据。**

例如：


集合的一个重要特点是：

```py
my_set = {1, 2, 2, 3, 3}

print(my_set)
```

结果只会保留不重复的元素。

**键值对（Key-Value Pair）**

# 可变类型和不可变类型

这是 Python 中一个比较重要的概念。

数据类型大致可以分为：

```text
不可变（Immutable）
可变（Mutable）
```

---

# 什么是不可变类型？

**不可变（Immutable）**

可以简单理解为：

> **对象创建后，其内容不能直接修改。**

常见不可变类型包括：

* `int`
* `float`
* `bool`
* `str`
* `tuple`
* `range`
* `NoneType`

例如：

```py
name = "Alice"
```

字符串本身不能直接修改。

如果：

```py
name = "Bob"
```

这并不是把原来的 `"Alice"` 修改成 `"Bob"`。

而是：

> **让变量 `name` 重新指向了另一个字符串对象。**

这叫：

**重新赋值（Reassignment）**

---

# 什么是可变类型？

**可变（Mutable）**

可以简单理解为：

> **对象创建后，可以修改其中的内容。**

常见可变类型包括：

* `list`
* `dict`
* `set`

例如：

```py
numbers = [1, 2, 3]

numbers.append(4)

print(numbers)
```

输出：

```text
[1, 2, 3, 4]
```

这里列表本身被修改了。

# 字符串（str）

# 字符串是不可变的

字符串属于：

**不可变类型（Immutable Type）**

例如：

```py
name = "Alice"
```

不能直接修改其中某一个字符。

但是可以生成一个新的字符串：

```py
name = "Bob"
```

这里实际上是让变量重新指向新的字符串。

---

# 访问字符串中的字符

字符串中的每个字符都有一个：

**索引（Index）**

索引从：

```text
0
```

开始。

例如：

```py
message = "Hello"
```

可以表示为：

```text
字符： H  e  l  l  o
索引： 0  1  2  3  4
```

因此：

```py
print(message[0])
```

输出：

```text
H
```

---

# 负数索引

Python 还支持：

**负数索引**

从字符串最后一个字符开始计算。

例如：

```text
字符：  H   e   l   l   o
正索引： 0   1   2   3   4
负索引：-5  -4  -3  -2  -1
```

所以：

```py
message = "Hello"

print(message[-1])
print(message[-2])
```

输出：

```text
o
l
```

可以记住：

> **`-1` 就是最后一个元素。**


进行拼接。

# 使用 += 拼接字符串


```py
greeting = greeting + developer
```

# f-string

Python 还有一种更加方便的字符串格式化方法：

**f-string**

它的全称是：

**Formatted String Literal**

即：

> **格式化字符串字面量。**

使用方法是在字符串前加：

```py
f
```

例如：

```py
developer = "Jessica"

greeting = f"My name is {developer}."

print(greeting)
```

输出：

```text
My name is Jessica.
```

其中：

```py
{developer}
```

表示：

> **把变量 `developer` 的值放到这里。**

相比大量使用 `+` 拼接，f-string 通常更加直观。

# 字符串切片

有时候我们只想取字符串的一部分。

这叫：

**切片（Slicing）**

基本语法：

```py
string[start:stop:step]
```

三个部分分别表示：

| 参数      | 含义             |
| ------- | -------------- |
| `start` | 从哪里开始          |
| `stop`  | 到哪里结束，但不包含这个位置 |
| `step`  | 每次走几步          |

例如：

```py
message = "Python is fun!"

print(message[0:6])
```

输出：

```text
Python
```

因为索引：

```text
0 1 2 3 4 5
P y t h o n
```

切片：

```py
[0:6]
```

包含 `0~5`，但不包含 `6`。

因此：

> **切片的结束位置通常是不包含的。**

---

# 切片可以省略参数

例如：

```py
message = "Python is fun!"

print(message[7:])
```

输出：

```text
is fun!
```

表示：

> 从索引 `7` 开始，一直取到最后。

还可以：

```py
print(message[:6])
```

表示：

> 从开头取到索引 `6` 之前。

---

# 切片的 step

例如：

```py
message = "Python is fun!"

print(message[::2])
```

输出：

```text
Pto sfn
```

这里：

```py
::2
```

表示：

> 每隔一个字符取一个。

# len() 函数

`len()` 用于获取：

> **对象的长度。**

例如：

```py
developer = "Jessica"

print(len(developer))
```

输出：

```text
7
```

因为：

```text
J e s s i c a
```

一共有：

```text
7
```

# 什么是作用域（Scope）？

**作用域（Scope）**

可以理解成：

> **一个变量可以在哪些地方被访问。**

简单来说：

```text
变量不是在任何地方都一定能使用。
```

Python 中经常会遇到：

* 局部作用域
* 封闭作用域
* 全局作用域
* 内置作用域

这些规则共同参与 Python 的：

**LEGB 查找规则**

---

# 局部作用域（Local Scope）

如果变量是在函数内部创建的：

```py
def my_func():
    num = 10
    print(num)
```

这里：

```py
num
```

属于函数内部的局部变量。

通常只能在这个函数内部直接访问。

例如：

```py
def my_func():
    num = 10
    print(num)

my_func()
```

输出：

```text
10
```

---

# 封闭作用域（Enclosing Scope）

如果一个函数里面又定义了另一个函数：

```py
def outer_func():
    msg = "Hello there!"

    def inner_func():
        print(msg)

    inner_func()

outer_func()
```

输出：

```text
Hello there!
```

这里：

```py
msg
```

属于外层函数。

内部函数：

```py
inner_func()
```

可以访问外层函数中的变量。

这种外层嵌套函数产生的作用域，就是：

**Enclosing Scope（封闭作用域）**

---

# 全局作用域（Global Scope）

如果变量定义在所有函数之外：

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + subtotal * tax
    return total

print(get_total(100))
```

输出：

```text
170.0
```

这里：

```py
tax = 0.70
```

位于函数外部，因此属于：

**全局作用域（Global Scope）**

函数内部可以读取这个变量。

---

# 内置作用域（Built-in Scope）

例如：

```py
print()

int()
type()
len()

```

这些名称来自 Python 的：

**Built-in Scope（内置作用域）**

例如：

```py
print(str(45))

```

输出：

```text

<class 'float'>
False
```

# LEGB 查找规则

Python 查找变量时，可以简单理解为按照下面的顺序：

```text
L → Local
局部作用域

E → Enclosing
封闭作用域

G → Global
全局作用域

B → Built-in
内置作用域
```

也就是：

```text
局部
 ↓
封闭
 ↓
全局
 ↓
内置
```

如果 Python 在前面的作用域找到了变量，就会停止继续查找。

初学阶段记住：

> **Python 会按照 LEGB 顺序寻找变量。**

即可。

# 常见比较运算符

| 运算符  | 含义    | 示例       | 结果      |
| ---- | ----- | -------- | ------- |
| `==` | 等于    | `3 == 4` | `False` |
| `!=` | 不等于   | `3 != 4` | `True`  |
| `>`  | 大于    | `3 > 4`  | `False` |
| `<`  | 小于    | `3 < 4`  | `True`  |
| `>=` | 大于或等于 | `3 >= 4` | `False` |
| `<=` | 小于或等于 | `3 <= 4` | `True`  |

# `==` 和 `=` 不一样

这是初学者非常容易犯的错误。

```py
=
```

表示：

> **赋值**

例如：

```py
age = 18
```

表示：

```text
把 18 保存给 age
```

而：

```py
==
```

表示：

> **判断两个值是否相等。**

例如：

```py
print(18 == 18)
```

输出：

```text
True
```

可以简单记：

```text
=   → 给变量赋值

==  → 比较是否相等
```

# if 条件判断

程序有时候需要根据情况做不同的事情。

例如：

```text
如果年龄 >= 18
    就显示“成年人”
```

这时候就需要：

```py
if
```

`if` 可以理解为：

> **如果……那么……**

例如：

```py
age = 18

if age >= 18:
    print("You are an adult")
```

输出：

```text
You are an adult
```

---

# if 的基本结构

```py
if 条件:
    要执行的代码
```

例如：

```py
score = 90

if score >= 60:
    print("考试通过")
```

程序会先判断：

```text
score >= 60
```

结果是：

```text
True
```

于是执行缩进后的代码。

---

# Python 非常重视缩进

Python 使用：

**缩进（Indentation）**

表示代码属于哪个代码块。

例如：

```py
if age >= 18:
    print("成年人")
```

这里：

```py
print("成年人")
```

前面的缩进非常重要。

不要写成：

```py
if age >= 18:
print("成年人")
```

这会产生错误。

因此要记住：

> **Python 中缩进不仅仅是排版，它还是代码结构的一部分。**

# elif：多个条件

如果有多个情况，可以使用：

```py
elif
```

`elif` 可以理解为：

> **否则如果……**

例如：

```py
age = 16

if age >= 18:
    print("成年人")
elif age >= 13:
    print("青少年")
```

输出：

```text
青少年
```

程序会按照顺序检查条件。

# else：其他情况

如果前面的条件全部不成立，可以使用：

```py
else
```

例如：

```py
age = 12

if age >= 18:
    print("成年人")

    print("青少年")

    print("儿童")
```

输出：


可以理解为：

```text
if

elif
否则如果……

else
否则……
```

# if、elif、else 执行流程

可以理解成：

```text
开始
 ↓
检查 if
 ↓
True？ ── 是 ──→ 执行 if
 ↓ 否
检查 elif
 ↓
True？ ── 是 ──→ 执行 elif
 ↓ 否
执行 else
```

在同一组：

```py
if
elif
elif
else
```

结构中，通常只会执行其中一个分支。

# 嵌套 if

`if` 里面还可以继续使用 `if`。

这叫：

**嵌套条件（Nested if）**

例如：

```py

if is_citizen:
    if age >= 18:
        print("You are eligible to vote")
else:
    print("You are not eligible to vote")
```

执行逻辑可以理解为：

```text
是不是公民？
    ↓
   是
    ↓
年龄是否 >= 18？
    ↓
   是
    ↓
允许投票
```

嵌套 `if` 可以使用，但嵌套太多会让代码越来越难读，因此实际开发中通常会尽量保持结构简单。

# 什么是真值和假值？

Python 中的很多数据，都可以被放进条件判断中。

例如：

```py
if value:
    ...
```

Python 会判断：

```text
value 是真值吗？
```

或者：

```text
value 是假值吗？
```

这种机制叫：

**Truthiness（真值判断）**

---

# 常见假值（Falsy）

以下数据在条件判断中会被当作：

```text
False
```

常见的包括：

```py
None
False
0
0.0
""
[]
()
{}
set()
```

例如：

```py
if "":
    print("执行")
else:
    print("不会执行")
```

因为：

```text
空字符串
↓
假值
↓
False
```

---

# 常见真值（Truthy）

与假值相反，很多非空、非零的数据都会被当作真值。

例如：

```py
print(bool(1))
print(bool("Hello"))
print(bool([1, 2, 3]))
```

输出：

```text
True
True
True
```

简单记：

```text
非零数字 → 真
非空字符串 → 真
非空列表 → 真
```

---

# bool() 函数

如果想直接查看一个值是真还是假，可以使用：

```py
bool()
```

例如：

```py
print(bool(False))
print(bool(0))
print(bool(""))
```

输出：

```text
False
False
False
```

再看：

```py
print(bool(True))
print(bool(1))
print(bool("Hello"))
```

输出：

```text
True
True
True
```

所以：

> `bool()` 可以把一个值转换成对应的布尔值。

---

# 布尔运算符

Python 有三个非常重要的布尔运算符：

```text
and
or
not
```

它们用于：

> **组合多个条件，形成更加复杂的判断。**

---

# and 运算符

`and` 可以理解成：

> **并且**

例如：

```py
age = 25
is_citizen = True

if is_citizen and age >= 18:
    print("You are eligible to vote")
```

这里必须同时满足：

```text
是公民
并且
年龄 >= 18
```

两个条件都成立，整个条件才成立。

---

# and 的短路

`and` 是一种：

**短路运算符（Short-circuit Operator）**

例如：

```py
False and something
```

因为第一个值已经是假值，所以整个结果不可能是真值。

因此 Python 不需要继续判断后面的内容。

可以理解成：

```text
第一个条件是假
↓
最终不可能为真
↓
停止判断
```

---

# 注意：and 不一定返回 True 或 False

这是一个非常容易被忽略的知识点。

例如：

```py
print(True and 25)
```

输出：

```text
25
```

因为 Python 的 `and` 并不一定直接返回布尔值。

它实际上会：

> **返回其中一个操作数。**

例如：

```py
print(False and 25)
```

输出：

```text
False
```

可以先记住：

```text
假值 and 任意值
→ 返回前面的假值

真值 and 任意值
→ 返回后面的值
```

---

# or 运算符

`or` 可以理解成：

> **或者**

例如：

```py
age = 19
is_student = True

if age < 18 or is_student:
    print("可以享受学生优惠")
```

只要：

```text
年龄 < 18
```

或者：

```text
是学生
```

其中一个成立，就可以执行。

---

# or 的短路

`or` 同样具有短路特性。

如果第一个值已经是真值：

```py
True or something
```

最终结果已经确定为真值。

因此 Python 不需要继续计算后面的内容。

可以理解成：

```text
第一个条件已经为真
↓
最终结果至少为真值
↓
停止继续判断
```

---

# or 也不一定返回 True 或 False

例如：

```py
print(19 or False)
```

输出：

```text
19
```

因为 `19` 是真值。

Python 直接返回：

```text
19
```

所以：

> **`and` 和 `or` 的结果可能是原来的操作数，而不一定是 `True` 或 `False`。**

在 `if` 条件中，我们通常只关心它最终是真还是假。

---

# not 运算符

`not` 可以理解成：

> **不是 / 取反**

它会把一个值的布尔意义反过来。

例如：

```py
print(not True)
```

输出：

```text
False
```

再例如：

```py
print(not False)
```

输出：

```text
True
```

---

# not 的常见例子

```py
print(not "")
print(not "Hello")

print(not 0)
print(not 1)
```

输出：

```text
True
False
True
False
```

原因：

```text
""     → 假值 → not 后变 True
"Hello" → 真值 → not 后变 False

0      → 假值 → not 后变 True
1      → 真值 → not 后变 False
```

与 `and` 和 `or` 不同：

> **`not` 的结果一定是 `True` 或 `False`。**

---

# not 在条件判断中的应用

例如：

```py
is_admin = False

if not is_admin:
    print("Access denied")
else:
    print("Welcome, Administrator!")
```

输出：

```text
Access denied
```

因为：

```text
is_admin = False
```

所以：

```text
not is_admin
↓
not False
↓
True
```

于是执行 `if` 中的代码。

---

# and、or、not 速查表

| 运算符   | 中文理解    | 作用            |
| ----- | ------- | ------------- |
| `and` | 并且      | 两边都满足时才满足     |
| `or`  | 或者      | 至少一个满足即可      |
| `not` | 不是 / 取反 | 把真值变假值，把假值变真值 |

最简单的记忆方法：

```text
and → 并且
or  → 或者
not → 不是
```

# 学习小结

这一篇主要掌握以下内容：

* **变量**：用一个名字保存数据。
* **数据类型**：不同的数据有不同的类型，例如 `int`、`float`、`str`、`bool`。
* **字符串**：可以进行索引、切片、拼接以及各种文字处理。
* **列表、元组、集合、字典**：都是用于保存多个数据的常见容器。
* **可变与不可变**：有些对象创建后不能直接修改，有些对象可以修改。
* **函数**：把一段代码封装起来，方便重复使用。
* **作用域**：决定变量可以在哪些地方被访问。
* **比较运算符**：用于比较数据，例如 `==`、`>`、`<`。
* **条件判断**：使用 `if`、`elif`、`else` 让程序根据不同情况执行不同代码。
* **布尔值**：`True` 和 `False` 是 Python 中最基础的逻辑值。
* **`and`、`or`、`not`**：用于组合和反转条件。
* **短路运算**：`and` 和 `or` 在结果已经确定时，会停止继续计算。
