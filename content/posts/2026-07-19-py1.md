# 一、什么是变量（Variable）？

在正式学习之前，先理解一个概念：

> **变量（Variable）就是一个用于存放数据的"盒子"，并且这个盒子拥有一个名字。**

可以把电脑的内存想象成一排储物柜。

例如：

|变量名|里面存放的数据|
|------|-------------|
|name|John|
|age|18|
|score|95|

程序通过**变量名**找到对应的数据。

例如：

```python
name = "John"
```

可以理解成：

> 创建了一个叫 **name** 的盒子，并把 `"John"` 放进去。

再例如：

```python
age = 25
```

意思就是：

> 创建了一个叫 **age** 的盒子，并把数字 **25** 放进去。

---

## 可以把变量理解成生活中的标签

例如有三个收纳盒：

📦 衣服

📦 零食

📦 书籍

盒子里面放的是内容，而盒子外面的标签就是变量名。

Python也是一样：

```
变量名 -------> 数据
```

例如：

```
name -------> "Tom"

age -------> 18

height -------> 180
```

以后程序需要这些数据时，只需要写变量名即可。

---

# 二、Python 如何声明变量？

很多编程语言声明变量时，需要先告诉电脑变量是什么类型。

例如 Java：

```java
String name = "Tom";
```

或者 C#：

```csharp
int age = 18;
```

甚至 JavaScript：

```javascript
let name = "Tom";
```

---

但是 **Python 不需要。**

Python 会自动判断变量保存的数据类型。

因此声明变量非常简单：

```
变量名 = 数据
```

语法格式：

```python
变量名 = 值
```

例如：

```python
name = "John Doe"
age = 25
```

执行以后：

```
name
 ↓
"John Doe"

age
 ↓
25
```

这里使用的是：

> **赋值运算符（Assignment Operator）**

也就是：

```
=
```

它表示：

> **把右边的数据赋值给左边的变量。**

注意：

很多初学者容易误认为：

```
=
```

表示数学里的"等于"。

实际上，在 Python 中：

```
=
```

读作：

> **赋值（Assign）**

例如：

```python
score = 100
```

不是：

> score 等于100

而是：

> 把100存入score变量。

# 三、变量可以存放哪些数据？

变量几乎可以保存任何数据。

例如：

## 1、字符串（String，简称 str）

字符串就是：

> **一串文本。**

例如：

```python
name = "Tom"
city = "Beijing"
```

字符串需要使用：

```
" "
```

或者

```
' '
```

包裹。

例如：

```python
"Hello"

'Hello'
```

都可以。

---

## 2、整数（Integer，简称 int）

例如：

```python
age = 18

score = 100
```

整数不用加引号。

---

## 3、小数（Float）

例如：

```python
height = 175.5
price = 19.9
```

---

## 4、布尔值（Boolean，简称 bool）

表示：

```
真(True)

假(False)
```

例如：

```python
is_student = True

is_login = False
```

---

# 四、变量可以随时修改

变量不是固定不变的。

例如：

```python
age = 18
```

后来：

```python
age = 19
```

现在：

```
age
 ↓
19
```

原来的18已经被新的值替换了。

这也是为什么它叫：

> Variable（变量）

意思就是：

> 可以变化的数据。

---

# 五、变量命名规则（必须遵守）

变量不是随便命名的。

Python规定了变量名必须满足下面四条规则。

---

## 规则一：只能以字母或下划线开头

✅ 正确：

```python
name = "Tom"

_age = 18

user = "Jack"
```

❌ 错误：

```python
1name = "Tom"

9age = 18
```

Python会报错：

```
SyntaxError
```

原因：

变量名不能以数字开头。

---

## 规则二：只能包含字母、数字和下划线

变量名可以包含：

- 英文字母（A-Z、a-z）
- 数字（0-9）
- 下划线（_）

例如：

```python
user_name

age18

student_score

hello123
```

下面这些是不允许的：

```python
user-name
```

因为：

```
-
```

表示减号。

例如：

```python
user name
```

因为：

空格不能出现在变量名里。

例如：

```python
user@name
```

因为：

```
@
```

不是合法字符。

---

## 规则三：区分大小写（Case Sensitive）

Python 是：

> **大小写敏感（Case Sensitive）**

意思就是：

下面三个变量完全不同：

```python
age = 18

Age = 20

AGE = 25
```

实际上它们是三个变量：

```
age

Age

AGE
```

互不影响。

建议：

开发中统一使用：

```
小写字母
```

避免混淆。

---

## 规则四：不能使用 Python 保留关键字（Keyword）

Python 内部已经占用了很多单词。

例如：

```
if

for

while

class

def

return

import
```

这些都是 Python 的**关键字（Keyword）**，不能作为变量名使用。

例如：

```python
if = 10
```

会直接报错。

---

# 六、变量命名规范（推荐遵守）

上面的四条规则是：

> **必须遵守**

下面这些属于：

> **推荐遵守（代码规范）**

虽然不遵守程序也能运行，但会影响代码质量。

---

## 规范一：全部使用小写字母

推荐：

```python
username
```

不要：

```python
UserName

USERNAME
```

---

## 规范二：多个单词使用下划线连接（Snake Case，蛇形命名法）

Python 官方推荐：

> **Snake Case（蛇形命名法）**

写法：

```
单词_单词_单词
```

例如：

```python
user_name

student_score

first_name

phone_number
```

因为看起来像蛇：

```
user_name

student_score
```

所以叫：

> Snake Case（蛇形命名法）

---

## 规范三：变量名要有意义

例如：

```python
user_age = 18
```

一眼就知道：

这是：

> 用户年龄。

再例如：

```python
book_price = 59.9
```

不用解释也知道：

这是：

> 图书价格。

不要写：

```python
a = 18

b = 59.9

x = "Tom"
```

别人完全不知道：

```
a

b

x
```

到底代表什么。

大型项目几万行代码中，这种变量几乎无法维护。

---

## 规范四：尽量不要使用拼音

例如：

```python
yonghu = "Tom"
```

虽然可以运行。

但是推荐：

```python
user = "Tom"
```

英文命名是国际通用标准。

# 八、什么是注释（Comment）？

程序不仅是写给电脑看的，也是写给人看的。

为了方便阅读代码，我们可以写：

> **注释（Comment）**

注释不会被 Python 执行。

---

## 单行注释

使用：

```python
#
```

例如：

```python
# 这是姓名
name = "Tom"
```

运行时：

Python 会忽略：

```
#
```

后面的内容。

---

## 多行注释

通常连续使用多个：

```python
#
```

例如：

```python
# 用户信息
# 姓名
# 年龄
# 地址
```

---

# 九、什么时候应该写注释？

适合写：

✅ 为什么这样写

```python
# 为了防止用户输入负数
```

✅ 复杂算法

```python
# 使用二分查找提高效率
```

✅ 功能说明

```python
# 计算商品总价格
```

---

不适合写：

```python
# 用户年龄
user_age = 18
```

因为：

变量名已经足够清楚。

好的变量名，本身就是最好的注释。

# 十、本章总结

|知识点|内容|
|-------|----|
|变量（Variable）|用于存储数据的"盒子"|
|声明变量|使用 `变量名 = 值`|
|赋值符号 `=`|表示把右边的值赋给左边变量|
|字符串（String / str）|文本数据，用引号包裹|
|整数（Integer / int）|不带小数的数字|
|小数（Float）|带小数点的数字|
|布尔值（Boolean / bool）|只有 `True` 和 `False` 两种值|
|变量命名规则|字母或下划线开头，只能包含字母、数字、下划线，区分大小写，不能使用关键字|
|推荐命名规范|小写字母、蛇形命名法（Snake Case）、见名知意|
|注释（Comment）|使用 `#` 编写，帮助解释代码，不会被程序执行|
