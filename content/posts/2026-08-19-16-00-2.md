## 安装代码编辑器或 IDE

在本地编写 Python 程序之前，你需要一个能够编辑代码的工具。

常见的选择包括**代码编辑器**和**集成开发环境（IDE）**。

IDE 是 **Integrated Development Environment** 的缩写，也就是“集成开发环境”。它通常会将代码编辑器、测试工具、终端等功能整合在一起，让你可以在一个应用程序中完成编写、运行和测试代码等工作。

一个常见的代码编辑器是 **VS Code**。

你可以访问：

`https://code.visualstudio.com/download`

下载适用于 **macOS、Windows 和 Linux** 的 VS Code。

其他常见的 Python 开发工具还包括：

* **PyCharm**
* **Spyder**

本课将使用 VS Code 作为示例。

## 创建 Python 项目文件夹

安装并打开 VS Code 后，首先需要打开一个用于存放 Python 项目的文件夹。

在 VS Code 左上角点击：

`File` → `Open Folder`

然后选择一个已经存在的文件夹，或者创建一个新的文件夹。

例如，你可以创建一个名为：

```text
python-projects
```

的文件夹，用来保存之后练习的 Python 程序。

这样做可以让不同的 Python 文件集中存放在同一个项目目录中。

## 创建 Python 文件

打开项目文件夹后，你可以在 VS Code 左侧看到**资源管理器（Explorer）**。

点击 **New File** 图标，然后创建一个名为：

```text
main.py
```

的文件。

这里的 `.py` 是 Python 文件的扩展名，它告诉编辑器和操作系统，这个文件包含 Python 代码。

最终，你的项目可能看起来像这样：

```text
python-projects/
└── main.py
```

## 编写第一个 Python 程序

打开 `main.py`，输入下面的代码：

```py
print("Hello, world!")
```

这段代码使用 `print()` 函数将文本输出到终端。

## 使用 VS Code 运行 Python 脚本

在 VS Code 中运行 Python 脚本有多种方法。

一种简单的方法是点击编辑器右上角的**运行按钮**。这个按钮通常看起来像一个播放按钮。

点击之后，VS Code 会打开终端，并运行当前的 Python 文件。

如果运行成功，你应该会看到：

```text
Hello, world!
```

这说明你的 Python 程序已经成功执行。

## 使用终端运行 Python 脚本

除了使用 VS Code 的运行按钮，你还可以直接在终端中运行 Python 脚本。

打开终端，然后使用：

```bash
python main.py
```

这里：

* `python` 用于启动 Python 解释器。
* `main.py` 是你想运行的 Python 文件。

运行之后，你应该看到：

```text
Hello, world!
```

## 为什么需要进入正确的文件夹？

运行：

```bash
python main.py
```

时，终端需要能够找到 `main.py` 文件。

因此，你通常需要先进入保存该文件的文件夹。

例如，如果你的文件位于：

```text
python-projects/
└── main.py
```

那么可以先使用 `cd` 命令进入这个文件夹：

```bash
cd python-projects
```

然后运行：

```bash
python main.py
```

这里的 `cd` 是 **change directory** 的缩写，用于切换当前终端所在的文件夹。

整个过程就是：

```bash
cd python-projects
python main.py
```

## 使用 `python3` 运行脚本

在某些 macOS 和 Linux 环境中，你可能需要使用 `python3` 而不是 `python`。

例如：

```bash
python3 main.py
```

这在系统同时存在多个 Python 版本，或者 `python` 命令不存在或指向旧版本 Python 时比较常见。

因此，如果：

```bash
python main.py
```

无法正常运行，可以尝试：

```bash
python3 main.py
```

具体应该使用 `python` 还是 `python3`，取决于你的操作系统和 Python 安装方式。

## 一个完整的运行流程

假设你已经创建了：

```text
python-projects/
└── main.py
```

并且 `main.py` 中包含：

```py
print("Hello, world!")
```

那么可以打开终端，进入项目文件夹：

```bash
cd python-projects
```

然后运行：

```bash
python main.py
```

如果你的系统需要使用 `python3`，则运行：

```bash
python3 main.py
```

最终输出：

```text
Hello, world!
```

## 总结

* 可以使用 **VS Code、PyCharm 或 Spyder** 等工具编写 Python 程序。
* Python 文件通常使用 `.py` 作为文件扩展名。
* 可以创建一个专门的项目文件夹，例如 `python-projects`。
* Python 程序可以直接通过 VS Code 的运行按钮执行。
* 也可以通过终端使用下面的命令运行：

```bash
python main.py
```

* 在某些系统中需要使用：

```bash
python3 main.py
```

* 如果 Python 文件不在当前终端目录中，需要先使用 `cd` 进入对应文件夹。
* 在学习过程中，可以尝试把课程中的示例保存为 `.py` 文件，然后自己运行和修改代码，通过实际运行结果理解 Python 的工作方式。
