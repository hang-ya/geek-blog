Python 可以在 **Windows、macOS 和 Linux** 等常见操作系统上运行。本节将介绍如何在这些系统上安装 Python，以及如何验证安装是否成功。

## 在 macOS 上安装 Python

在 macOS 上安装 Python，比较简单的方法是从 Python 官方网站下载安装程序。

首先，访问：

`https://www.python.org/`

将鼠标移动到页面顶部的 **Downloads** 菜单上，系统会显示适用于当前操作系统的 Python 下载选项。

然后按照以下步骤操作：

* 点击显示当前 Python 版本的下载按钮，系统会自动下载一个 `.pkg` 安装文件。
* 下载完成后，打开 `.pkg` 安装程序。
* 在安装窗口中点击 **继续**。
* 按照安装程序的提示继续操作，直到进入 **安装类型** 页面。
* 点击 **安装** 开始安装 Python。
* 如果系统要求输入密码，请输入你的计算机密码。
* 等待安装完成。
* 看到安装成功的提示后，点击 **关闭**。

安装完成后，可以打开终端验证 Python 是否安装成功。

```bash
python --version
```

或者：

```bash
python3 --version
```

如果安装成功，你会看到类似下面的输出：

```text
Python 3.x.x
```

其中 `3.x.x` 表示你当前安装的 Python 版本。

## 什么是终端？

在使用 Python 的过程中，你会经常看到“终端”这个词。

**终端**是一种基于文本的界面，你可以通过输入命令与计算机进行交互。

不同操作系统通常使用不同的终端程序：

* **macOS**：Terminal
* **Windows**：命令提示符（Command Prompt）或 PowerShell
* **Linux**：不同桌面环境可能提供不同的终端，例如 GNOME Terminal 或 Konsole

例如，在终端中运行：

```bash
python3 --version
```

计算机会执行这个命令，并告诉你当前 Python 的版本。

## 什么是 Python 解释器？

安装 Python 后，你还可以直接启动 **Python 解释器**。

Python 解释器是负责读取 Python 代码、解释代码并执行代码的程序。

你可以在终端中运行：

```bash
python
```

或者：

```bash
python3
```

进入 Python 解释器后，你通常会看到类似这样的提示符：

```text
>>>
```

这意味着 Python 正在等待你输入代码。

例如：

```py
print('Hello world!')
```

运行后会得到：

```text
Hello world!
```

要退出 Python 解释器，可以输入：

```py
exit()
```

## `python` 和 `python3` 有什么区别？

在一些较旧的 macOS 和 Linux 系统中，`python` 命令可能指向 Python 2，而 `python3` 则指向 Python 3。

例如，如果运行：

```bash
python --version
```

得到：

```text
Python 2.7.18
```

那么你的系统中的 `python` 命令可能仍然指向 Python 2。

Python 2 已经停止维护，因此进行新的 Python 开发时应该使用 Python 3。

可以尝试：

```bash
python3 --version
```

然后使用：

```bash
python3
```

启动 Python 3 解释器。

不过，在较新的系统中，`python` 也可能已经默认指向 Python 3。因此，实际使用哪个命令取决于你的系统配置。

## 在 Windows 上安装 Python

在 Windows 上，可以从 Python 官方网站下载安装程序。

访问：

`https://www.python.org/`

然后将鼠标移动到 **Downloads** 菜单上。

在弹出的窗口中找到 **Download for Windows**，并点击当前 Python 版本的下载按钮。

下载完成后：

* 双击下载的 Python `.exe` 安装程序。
* 在安装程序中找到 **Add python.exe to PATH** 选项。
* **勾选 `Add python.exe to PATH`**。
* 点击 **Install Now**。
* 等待安装完成。

其中，`Add python.exe to PATH` 非常重要。

启用这个选项后，Windows 可以更方便地在命令行中找到 Python。这样你以后就可以直接使用：

```bash
python
```

或者：

```bash
python --version
```

而不需要手动输入 Python 的完整安装路径。

## 验证 Windows 上的 Python 安装

安装完成后，打开 PowerShell 或命令提示符。

运行：

```bash
python --version
```

如果安装成功，你应该会看到类似：

```text
Python 3.x.x
```

你还可以直接运行：

```bash
python
```

进入 Python 解释器。

然后测试一段简单的代码：

```py
print('Hello world!')
```

如果终端输出：

```text
Hello world!
```

说明 Python 已经可以正常运行。

## 在 Linux 上安装 Python

许多常见的 Linux 发行版，例如 Ubuntu、Debian 和 Fedora，都提供 Python。

首先打开终端，然后尝试运行：

```bash
python --version
```

如果没有找到 Python，可以尝试：

```bash
python3 --version
```

如果其中一个命令显示了 Python 版本，就说明系统中已经安装了对应版本的 Python。

例如：

```text
Python 3.x.x
```

如果两个命令都无法显示 Python 版本，可以访问：

`https://www.python.org/`

查找适合你的 Linux 系统的安装方式。

不同 Linux 发行版使用的安装工具和软件包管理方式可能不同，因此具体安装步骤会根据你的发行版有所不同。

## 如何确认 Python 已经可以使用？

无论你使用 Windows、macOS 还是 Linux，都可以通过运行一个简单的 Python 程序来测试安装。

首先打开终端或命令行工具。

然后进入 Python 解释器：

```bash
python
```

或者：

```bash
python3
```

接着输入：

```py
print('Hello world!')
```

如果看到：

```text
Hello world!
```

就说明 Python 解释器已经能够正常运行。

## 总结

* Python 可以安装在 **Windows、macOS 和 Linux** 等操作系统上。
* Windows 和 macOS 可以从 Python 官方网站下载安装程序。
* macOS 通常可以使用 `python3 --version` 检查 Python 版本。
* Windows 安装时建议勾选 **Add python.exe to PATH**。
* Linux 可以使用 `python --version` 或 `python3 --version` 检查 Python 是否已经安装。
* `python` 和 `python3` 在不同系统上的指向可能不同。
* **Python 解释器**负责读取、解释并执行 Python 代码。
* 可以通过运行下面的代码测试 Python 是否正常工作：

```py
print('Hello world!')
```
